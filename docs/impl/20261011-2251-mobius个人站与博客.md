# 实现:mobius.github.io 个人站与博客

- 时间:2026-10-11 22:51(+0800),提交 `d5e8081`/`aac7578`
- 需求(用户):根据公开 repo 做 Pages 首页,每个 repo 一篇 blog 说明,简约风

## 落地

- `mobius/mobius.github.io` 仓库原本不存在 → 用本机 git 凭据管理器令牌经 GitHub API 创建(公开仓库)
- 站点:`D:/Github/mobius.github.io`,纯静态(无 JS 无构建,`.nojekyll` 跳过 Jekyll)
  - `index.html`:hero + 32 个原创仓库列表(名称→说明页)+ 29 个 fork 简列 + Homeworld 讲解站入口
  - `blog.html`:32 篇按时间倒序索引
  - `posts/<repo>.html` ×32:中文简介(基于各仓库 README 抓取提炼)+ 语言/日期/GitHub 链接 + README 摘录
  - `style.css`:单栏 46rem、系统字体、单强调色、`prefers-color-scheme` 自动暗色
- `_intros.json`(抓取中间产物)留在本地不提交;`.gitignore` 排除

## 调试记录

1. 匿名 GitHub API 被共享出口 IP 限流 → 改用 `git credential fill` 取本机存储令牌(不回显)
2. README 摘录残留 markdown 链接语法(`[text](url)`、`*斜体*`)→ intro() 增加链接/强调剥离正则,重新生成,提交 `aac7578`
3. 验证时浏览器吃到 Pages 10 分钟 CDN 缓存显示旧页 → 带 `?cb=` 参数绕缓存确认,实际线上已是新版

## 经验

- 用户站仓库(`<user>.github.io`)推送 main 即自动发布(~30s),无需手动开 Pages
- GitHub Pages(项目站/用户站)默认**不带** COOP/COEP 头,依赖 SharedArrayBuffer 的 wasm 站点必须顶层挂 coi-serviceworker 或改用自带响应头的托管
