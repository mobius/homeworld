## 调试记录

1. **iframe 黑屏(SharedArrayBuffer undefined)**:coi-serviceworker 在 iframe 内不生效 → 换 `serve.py` 下发 `Cross-Origin-Opener-Policy: same-origin` + `Cross-Origin-Embedder-Policy: require-corp`,顶层与 iframe 一起跨源隔离,游戏正常
2. **静态服务绑定 IPv6 导致 127.0.0.1 拒绝连接**:改为显式 `("127.0.0.1", port)` + ThreadingHTTPServer
3. **物理帧力采样为 0**:源码在物理帧末 `vecZeroVector(force)` 清零(冲量语义),采样钩子必须挂在 physics 之前 —— 忠实移植时发现的典型语义陷阱
