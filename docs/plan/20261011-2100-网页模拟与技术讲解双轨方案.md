# 方案:网页版 Homeworld 模拟 + 技术细节讲解

- 时间:2026-10-11 21:00(+0800)
- 需求(用户):① 远端切到 mobius/homeworld;② 实现网页版 homeworld 模拟;③ 在网页版上做技术细节讲解模拟
- 追加指示:优先用现成 wasm 实现,不从头造;保证功能完整,可用 demo 资源

## 双轨架构

1. **真机游戏(现成引擎)**:GardensOfKadesh wasm 包原样落地 `web/engine/`,demo 资源直接可玩 —— 满足"完整功能"
2. **原理沙盒(自研,轻量)**:wasm 是黑盒,内部机制看不到;用 three.js 写 JS 移植展示
   - physics.c:`physApplyForceToObj` / `physUpdateObjPosVelShip` 忠实移植(冲量语义、限速、倾斜)
   - formation.c:DELTA/DELTA3D 右左交替槽位算法
   - GenericInterceptor.c:whip-strafe 攻击掠袭状态机
   - CommandNetwork.c:命令对象入队→帧首处理
3. **教学手册**:8 章,每章真实源码摘录(文件:行号)+ 场景联动演示 + 实时数据

## 发布

- 本地:`serve.py`(带 COOP/COEP 头)
- 线上:homeworld 仓库 `gh-pages` 分支 → https://mobius.github.io/homeworld/(Pages 无隔离头 → 门户顶层挂 coi-serviceworker 补头)

## 关键风险与对策

| 风险 | 对策 |
|---|---|
| iframe 内 coi-serviceworker 失效(实测) | 顶层页挂 SW 补头 / 本地 serve.py 直接带头 |
| 67MB 资源入库膨胀 | master/gh-pages 均纳入(demo 可分发,<100MB/文件限制);本地开发提供 download.sh |
| 合成点击不进游戏 | 键盘 Enter 驱动菜单;真人鼠标无碍 |
