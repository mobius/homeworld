# 调研:现成 Homeworld Web/WASM 实现

- 时间:2026-10-11 21:35(+0800)
- 迭代:网页模拟任务中途,用户指示「找别人做好的 web wasm 实现,不需要自己从头做」

## 结论

采用 **GardensOfKadesh**(HomeworldSDL 的官方后续):

- HomeworldSDL:把 Relic 2003 开源的原版 C 源码移植到 SDL2,组织仓库 `HomeworldSDL/HomeworldSDL`(GitHub 为镜像,主仓在 GitLab)
- 项目已迁移为 **gardens-of-kadesh**(GitLab),官方提供浏览器 demo,基于 Emscripten

## 在线 demo 包组成(实测探测,gitlab.io 托管)

| 文件 | 大小 | 说明 |
|---|---|---|
| homeworld.js | 615,658 B | Emscripten 胶水层 |
| homeworld.wasm | 3,326,355 B | 整个引擎编译产物 |
| homeworld.data | 67,297,428 B | 打包的官方 demo 资源(可自由分发) |
| homeworld.worker.js | 294 B | pthread worker 垫片 |
| coi-serviceworker.min.js | 3,009 B | 无 COOP/COEP 头时补头的 ServiceWorker |
| index.html | ~103 KB | emscripten 外壳 |

仓库 `wasm/` 目录只含加载页与交叉编译配置,二进制产物走 CI —— 因此选择直接下载线上完整包落地本地。

## 验证

下载 7 个文件到 `web/engine/`,本地静态服务 + headless Chromium 实测:主菜单正常,TRAINING 教学关可完整进入(母舰渲染、教程文本、任务状态)。键盘 ↑↓/Enter 可驱动菜单;合成鼠标点击会被 SDL 事件过滤(真人鼠标无此问题)。
