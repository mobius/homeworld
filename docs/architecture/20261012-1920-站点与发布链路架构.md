- 时间:2026-10-12 19:20(+0800)
- 范围:homeworld(源码+网页)与 mobius.github.io(个人站)两仓库的分层与发布流

## 仓库分层

```
mobius/homeworld                     mobius/mobius.github.io
├── master                           └── main(即站点根)
│   ├── 原版 C 源码(上游快照)          ├── index.html  首页(仓库列表+在线项目入口)
│   ├── 6 份中文架构文档                ├── blog.html   博客索引(32 篇)
│   ├── web/                          └── posts/      每仓库一篇说明
│   │   ├── index.html  门户(游戏/沙盒/教学)
│   │   ├── engine/     GardensOfKadesh wasm 包
│   │   └── js/         sim/ui/teach
│   ├── serve.py        本地 COOP/COEP 服务
│   ├── docs/           过程文档(本目录)
│   └── AGENTS.md       开发者声明
└── gh-pages = master:web 平铺 → mobius.github.io/homeworld/
```

## 发布链路

| 目标 | 方式 | 关键点 |
|---|---|---|
| mobius.github.io/homeworld/ | 推 `gh-pages` 分支(README 有刷新脚本) | 顶层挂 coi-serviceworker 补 COOP/COEP,否则 iframe 内 wasm 拿不到 SharedArrayBuffer |
| mobius.github.io/ | 推 `main` 即自动发布 | 无需手动开 Pages |
| 本地开发 | `python serve.py 8931` | 直接发头,比 coi-serviceworker 方案稳 |
